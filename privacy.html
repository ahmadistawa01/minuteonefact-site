Privacy policy

One Minute, One Fact uploader · last updated 4 November 2026

This policy covers the One Minute, One Fact uploader, a command-line tool that publishes finished videos to the YouTube channel @MinuteOneFact. The tool runs on its owner's own computer and is operated only by them.

Who this applies to

One person: the owner of the channel, who is also the only operator of the tool. The uploader has no sign-up, no accounts, and no other users. It never requests access to anyone else's Google account.

Use of YouTube API Services

The uploader uses YouTube API Services. By authorising it you accept the YouTube Terms of Service, and Google's handling of data it receives is described in the Google Privacy Policy.

What is accessed, and what is kept

The tool requests one OAuth scope, https://www.googleapis.com/auth/youtube.upload, which permits uploading a video and nothing else. It cannot read the channel's analytics, its subscribers, its comments, or any other account data, because that scope does not grant it.

Authorising it produces an access token and a refresh token. Both are written to a single file on the owner's own computer and are never transmitted anywhere except to Google, to perform the upload the owner asked for. No data is sent to any third party, no analytics or tracking of any kind is collected, and nothing is stored on a server, because the tool has no server.

Deleting the stored data

The stored tokens are the only data the tool holds. Deleting the token file removes them completely and immediately; there is no copy anywhere else.

Access can also be withdrawn from Google's side at any time, at myaccount.google.com/permissions, which revokes the tokens whether or not the local file is deleted. Doing so stops the tool working until it is authorised again.

Videos that have been uploaded

Videos published to the channel are governed by YouTube, not by this tool. They can be edited or deleted by the channel's owner in YouTube Studio.

Changes

If this policy changes, the date at the top of this page changes with it.
