# One Minute, One Fact — site

The public pages for the YouTube channel [@MinuteOneFact](https://www.youtube.com/@MinuteOneFact)
and the command-line tool that uploads to it.

Three static pages, no build step. They exist because Google asks for them:
the YouTube API audit form wants a home page, a privacy policy and terms at
real https urls, and the OAuth consent screen wants the same three before the
app can leave Testing.

Served by GitHub Pages from the repository root.
